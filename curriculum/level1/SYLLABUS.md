# Level 1 syllabus (30 lessons, ~30 min each)

Every Maya string must be attested in YUA-ES-CCC (context ids in brackets) or Wiktionary; `maya lint` enforces it.
Grammar is taught organically: one narrator sentence per lesson, never a paradigm table.
